# Getting Support

We provide structured channels to help you get assistance, report issues, and discuss features for MailGable.

---

## Where to Get Help

| Topic | Channel | Description |
| :--- | :--- | :--- |
| **Bug Reports** | [GitHub Issues](https://github.com/XiantingWu/MailGable/issues/new?template=bug_report.yml) | Report unexpected behavior or reproducible defects |
| **Feature Requests** | [Feature Requests](https://github.com/XiantingWu/MailGable/issues/new?template=feature_request.yml) | Propose new capabilities or improvements |
| **Questions** | [GitHub Issues](https://github.com/XiantingWu/MailGable/issues/new) | Ask usage questions and share setup notes |
| **Security Vulnerabilities** | [Private Advisory](https://github.com/XiantingWu/MailGable/security/advisories/new) | Disclose security issues privately (Private Vulnerability Reporting is enabled at public cutover; see `SECURITY.md`) |

---

## Support Scope & Guidelines

Support is **best-effort** by a single maintainer; there is no response-time commitment.

* **Public Logs**: When seeking support in public issues or discussions, **always sanitize your logs and configuration**. Remove domain names, personal email addresses, Cloudflare IDs, and API tokens.
* **No Production Credential Auditing**: Maintainers will not inspect or debug live production credentials or private server environments in public forums.
